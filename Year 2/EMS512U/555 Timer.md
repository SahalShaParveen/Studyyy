## Pinout

| Pin | Name   | What it does                                 |
| --- | ------ | -------------------------------------------- |
| 1   | GND    | Connect to 0V                                |
| 2   | TRIG   | Starts a timing cycle                        |
| 3   | OUT    | Produces the output signal                   |
| 4   | RESET  | Enables/disables the timer                   |
| 5   | CTRL   | Changes the internal reference voltage       |
| 6   | THRESH | Detects when a timing voltage is high enough |
| 7   | DISCH  | Discharges the timing capacitor              |
| 8   | VCC    | Positive power supply                        |
